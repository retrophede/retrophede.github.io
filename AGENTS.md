# Portfolio workflow

- Keep changes local. Do not push or deploy unless the user explicitly requests deployment.
- Do not use Framer unless the user explicitly requests it.
- Every UI change must work on mobile as well as desktop. Verify portrait (390×844 and 320×568) and landscape (844×390) layouts, including controls, folder navigation, and both themes when affected.
- Preserve the single-screen console layout: no vertical page scrolling or clipped controls; horizontal scrolling belongs to the project shelf.
- Preserve touch-friendly controls, keyboard navigation, reduced-motion support, and the sound toggle.
